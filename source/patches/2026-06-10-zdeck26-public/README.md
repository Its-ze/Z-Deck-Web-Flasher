# Z-Deck 0.2.25-cyberdeck Public Source Patches

This archive contains the public-safe source patches used for the Z-Deck `0.2.25-cyberdeck` / firmware `2.8.0.zdeck26` build.

The zdeck26 patch stack adds the sidebar gutter/header overlap fix on top of zdeck25 map UI changes. It does not bundle private channel URLs, private PSKs, admin keys, or owner-specific settings.
