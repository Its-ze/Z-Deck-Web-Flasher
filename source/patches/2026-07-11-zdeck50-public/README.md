# Z-Deck 0.2.49-cyberdeck Public Source Patch Archive

Public-safe source patch archive for firmware `2.8.0.zdeck50` / pack `0.2.49-cyberdeck`.

This release adds the guarded Z-Deck-to-MeshCore boot switch, validates the MeshCore app 1 signature before rebooting, and retains the zdeck49 map-legibility changes. The separate `meshcore-zdeck-return.patch` at the parent patch directory documents the MeshCore UI return path.

No private channel URLs, PSKs, admin keys, Wi-Fi passwords, owner-specific settings, or user device configurations are bundled.
