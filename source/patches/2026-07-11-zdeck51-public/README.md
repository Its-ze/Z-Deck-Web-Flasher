# Z-Deck 0.2.50-cyberdeck Public Source Patch Archive

Public-safe source patch archive for firmware `2.8.0.zdeck51` / pack `0.2.50-cyberdeck`.

This release rebuilds map behavior around a standalone state controller, adds persistent `MAP`, `COMP`, `RADAR`, and `ALERT` controls, keeps fallback views ready for the first live GPS fix, cancels auto-centering after manual map interaction, resumes it when Follow GPS is enabled, and uses one latitude-aware distance calculation for mesh range.

No private channel URLs, PSKs, admin keys, Wi-Fi passwords, owner-specific settings, raw backups, or user device configurations are bundled.
