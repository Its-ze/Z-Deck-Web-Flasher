# Z-Deck 0.2.26-cyberdeck Source Patch Archive

This folder contains the public-safe patch stack used to build `2.8.0.zdeck27` / `0.2.26-cyberdeck` from Meshtastic firmware `2.8`.

The zdeck27 change makes the home screen show the configured owner name instead of a hard-coded CyberDeck title, while keeping the zdeck26 sidebar gutter and top-panel overlap fixes.
