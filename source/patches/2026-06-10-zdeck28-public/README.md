# Z-Deck 0.2.27-cyberdeck Source Patch Archive

This folder contains the public-safe patch stack used to build `2.8.0.zdeck28` / `0.2.27-cyberdeck` from Meshtastic firmware `2.8`.

The zdeck28 change keeps the configured owner-name home header while clipping it between the left battery/percent block and right-side status icons, and keeps real battery percent visible even when a full/USB-powered T-Deck reports charge value 101.
