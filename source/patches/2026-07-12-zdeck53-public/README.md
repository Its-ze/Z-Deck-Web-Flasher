# Z-Deck zdeck53 source archive

This archive contains the public source changes for `2.8.0.zdeck53` / `0.2.52-cyberdeck`.

- `device-ui-smart-map.patch` adds the no-tile coordinate grid, center reticle, and clearer GPS acquisition states.
- `zdeck-full-source.patch` is the complete public Z-Deck patch against Meshtastic firmware branch `2.8`.

The update is app-only. It does not contain private channel settings, keys, Wi-Fi credentials, owner data, or admin configuration.
