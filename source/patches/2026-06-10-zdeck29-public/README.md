# Z-Deck 0.2.28-cyberdeck Source Patch Archive

This folder contains the public-safe patch stack used to build `2.8.0.zdeck29` / `0.2.28-cyberdeck` from Meshtastic firmware `2.8`.

The zdeck29 change exposes app-only Wi-Fi OTA controls in the active LVGL Settings screen as a visible `Z-Deck OTA` block with CHECK, APPLY, STATUS, BACKUP SD, and guarded RESTORE SD buttons plus a live readout.
