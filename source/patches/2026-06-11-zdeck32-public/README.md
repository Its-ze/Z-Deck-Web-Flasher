# Z-Deck 0.2.31-cyberdeck Source Patch Archive

This folder contains the public-safe patch stack used to build `2.8.0.zdeck32` / `0.2.31-cyberdeck` from Meshtastic firmware `2.8`.

The zdeck32 change adds `device-ui-compass-pages.patch`, which makes the non-map position pages render as real compass/radar/alert panels instead of staying visually stuck on the map. It also compacts the map options overlay so the menu fits on the physical T-Deck display.

No private channel data, PSKs, channel URLs, Wi-Fi credentials, admin keys, owner-specific settings, or saved chats are bundled in this public source archive.
