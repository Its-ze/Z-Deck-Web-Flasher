# zdeck56 Public Source Patch Set

- `zdeck-full-source.patch`: complete Meshtastic 2.8 Z-Deck patch stack.
- `device-ui-blackberry-shell.patch`: integrated 4x4 launcher, Z-Deck dashboard, Mesh Networks hub, and display shell.
- `meshcore-zdeck-return.patch`: MeshCore saved-slot return flow and `Z-DECK` companion UI.

The release adds explicit dedicated-MeshCore readiness, cached image validation, and a dashboard that no longer exposes the stock Meshtastic home panel. No private channel material or device-specific credentials are included.
