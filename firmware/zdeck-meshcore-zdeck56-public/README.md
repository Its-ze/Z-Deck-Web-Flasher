# MeshCore Companion For zdeck56 Layout

MeshCore companion image for the dedicated `meshcore` app partition at `0xa10000`. Its on-device `Z-DECK` page reads the saved Z-Deck A/B slot, validates that image, and returns to the correct Z-Deck slot.

This image is used only by the dual-system USB installer. It does not contain user settings, private channels, keys, or chats.
