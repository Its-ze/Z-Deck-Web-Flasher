Recovery assistant

When the device stays in programming mode

Use this when flashing completes but the board still shows the ESP32-S3 ROM loader or never reaches the Meshtastic app.

Pick the state you see

If the flash log says verified but the same USB serial port stays available for flashing, the BOOT/trackball/GPIO0 line is probably still held low.

Normal boot

  1. Release the center trackball / BOOT control completely.
  2. Tap RESET once, or unplug and reconnect USB normally.
  3. Wait for the Z-Deck screen instead of selecting the port again.
  4. Use the Meshtastic app or CLI only after the app-side port appears.

Do not reflash just because the ROM loader still answers; a verified flash usually means the bytes are already on the board.

Feature set

What this build does

Right-side sidebar

System setting controls sidebar placement, defaults to the right side, persists in /zdeck_sidebar.cfg, and keeps top panels clear of the rail.

Safe header lane

The home header clips the owner title between the battery/percent block and right-side status icons.

SD settings backup

Backup and restore Meshtastic preferences from /zdeck/backups/preferences.proto on the SD card.

Safer updates

The Settings OTA block shows CHECK, APPLY, STATUS, BACKUP SD, and guarded RESTORE SD controls with a live readout.

Wi-Fi scan setup

The T-Deck Wi-Fi popup can scan nearby networks, show signal strength and open/locked status, and fill the selected SSID for you.

Bluetooth readiness

Production checks track the Windows adapter, BLE scan path, and T-Deck Bluetooth config so pairing issues are visible instead of silent.

Cleaner home screen

Modern Field UI, clipped LoRa RX text, clearer TX/RX chips, and fixed front-page spacing.

More themes

Amber Terminal, Slate Signal, and Arctic High are selectable from the on-device theme menu alongside the existing themes.

Map pages

Mesh map, Live compass, DF/Radar, and Distance alert views with persistent default selection, Center, GPS/MAP coordinate labels, GPS/node recenter recovery, and tile progress readouts.

GPS startup

Fresh T-Deck installs keep GPS active on RX44/TX43 instead of inheriting power-save mode.

SD field storage

Visible SD setup progress, prepared-card detection, map folders, ringtones, logs, and chat history.

Better chats

Newest-first direct/group chat pickers, stable node-name fallback labels, and clearer hop/send status.

Before flashing

Keep recovery simple

  1. Use Chrome or Edge with Web Serial.
  2. Confirm this is a T-Deck/T-Deck Plus class ESP32-S3 device.
  3. Keep bootloader mode available for rollback.
  4. Do not put private channel URLs or PSKs in public issues.

Local privacy

SD backups are sensitive

The settings backup contains Meshtastic config, channels, PSKs, owner data, and security keys. Treat the card as private local storage.

Z-Deck 0.2.36-cyberdeck

Firmware 2.8.0.zdeck37 fixes duplicate found-device entries by deduping repeated NodeDB records in the node list, message destination picker, and favorite-node pages.
