Use Chrome or Edge with Web Serial enabled. Serial access was blocked. Reload and allow the browser prompt.

Bootloader Mode

  1. Plug in the T-Deck over USB.
  2. Hold the center trackball / BOOT control.
  3. Tap RESET, then release RESET.
  4. Release BOOT after the serial port appears.

Custom Firmware

Paste another ESP Web Tools manifest URL to flash a different hosted build.

Default manifest: bundled Z-Deck firmware.

After Flash

Set your Meshtastic owner, region, GPS, channels, and device keys after flashing. Private channels, PSKs, channel URLs, and admin keys stay outside this public repo.

Release Notes

Z-Deck is Meshtastic firmware with a custom T-Deck layer: Z-Deck Classic UI, GPS/compass refresh work, map/cache changes, a map waiting/status card, clearer TX/RX message chips, screen correction tools, USB API recovery behavior, and an SD-card message journal.

Message journal entries are stored as plaintext local history on the SD card.
