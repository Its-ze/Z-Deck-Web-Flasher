Public 0.2.26

Z-Deck 0.2.26-cyberdeck is experimental T-Deck firmware based on Meshtastic `2.8` for the `t-deck-tft` target.

Keep bootloader recovery available and do not flash non-T-Deck hardware.

Flash

  1. Open the web flasher in Chrome or Edge.
  2. Plug in the T-Deck over USB.
  3. Use bootloader mode if the port does not appear.
  4. Click Connect and flash.
  5. Reboot and configure Meshtastic settings.

Bootloader Mode

  1. Hold center trackball / BOOT.
  2. Tap RESET.
  3. Release RESET.
  4. Release BOOT after the serial port appears.

Custom Layer

Z-Deck keeps Meshtastic radio behavior and adds the Modern Field on-device UI, owner-name home header, right-side sidebar system setting with fixed gutter/header overlap protection, clipped home RX status, newest-first chat ordering, stronger node-name fallbacks, GPS/compass refresh changes, fresh GPS startup defaults, easier map page switching with stable SD tile style handling, persistent default map page storage, tile progress and missing-tile status, map Center and late GPS/node auto-center recovery, Wi-Fi scan/select setup, clearer TX/RX message chips, fixed I2S ringtone playback, screen correction tools, USB recovery behavior, disabled USB SD mass storage, an SD prepare/reset tool with visible progress, SD popup controls, SD ringtone discovery, SD settings backup/restore, an SD message journal, and app-only Wi-Fi updates from Home Action > Z-Deck Updates.

Wi-Fi Updates

After 0.2.26 is installed once by USB, use the T-Deck Wi-Fi popup's Scan button, pick your network from the dropdown, then use Home Action > Z-Deck Updates > Check for Updates and Apply Update. The same update menu remains available under System > Z-Deck Updates.

Hosted Z-Deck updates must declare `app-only`; Apply Update writes and verifies the SD settings backup first, and that update mode preserves Meshtastic config, channels, keys, owner settings, and SD chat history.

Privacy

The public flasher does not include private channels, PSKs, channel URLs, admin keys, saved chats, or personal node config.

The SD journal and settings backup are local plaintext storage. The settings backup contains channels/PSKs and security keys, so treat the card as private.

Compatibility

Target: LILYGO T-Deck / T-Deck Plus class devices, ESP32-S3, `t-deck-tft`, 16MB flash layout.
